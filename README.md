# 4대보험 계산기 (2026년 기준)

직원 고용 시 근로자가 부담하는 4대보험, 회사가 부담하는 4대보험,
그리고 회사의 총인건비를 계산해 주는 한국어 웹앱입니다.

## 4대보험이란?

한국에서 직장에 다니면 의무적으로 가입하는 4가지 사회보험입니다.

| 보험 | 근로자 부담 | 회사 부담 |
|------|:---------:|:--------:|
| 국민연금 | ✅ | ✅ |
| 건강보험 (+ 장기요양) | ✅ | ✅ |
| 고용보험 | ✅ | ✅ |
| 산재보험 | ❌ | ✅ (회사만) |

## 사용 방법

별도 설치가 필요 없습니다. `index.html` 파일을 웹 브라우저로 열기만 하면 됩니다.

1. 월 급여를 입력합니다.
2. "계산하기" 버튼을 누릅니다.
3. 근로자 부담액, 회사 부담액, 총인건비를 확인합니다.

## 기술 스택

- HTML
- CSS
- JavaScript (순수 자바스크립트, 프레임워크 없음)

> ⚠️ 보험요율은 법령에 따라 매년 바뀔 수 있습니다.
> 이 계산기의 요율은 화면에서 직접 수정할 수 있도록 만들 예정입니다.
